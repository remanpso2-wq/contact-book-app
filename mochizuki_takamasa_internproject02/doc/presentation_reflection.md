# インターン振り返り & 課題レビュー
課題①（PoC）/ 課題②（拡張）

---

## ゴール
- 8年間のブランクからの**復帰体験**を共有
- 課題①/②の**成果**と**難しさ**を整理
- 次に**自走できる改善計画**を提示

---

## 8年間のブランクからの復帰
- 業務としての開発は**約8年ぶり**
- まずは環境構築とツールの再キャッチアップ  
  - Git / GitLab フロー、venv、依存管理、PowerShell の実行ポリシー  
  - Flask / SQLAlchemy / Jinja2 など “今の定番” を再学習
- **戸惑いも大きかった**が、手を動かし続けて**勘が戻ってきた**

---

## 課題の難易度（正直ベース）
- **要件の見極めが難しい**：前登校日・重複禁止・既読POSTなど、**サーバ側での厳密化**が肝
- エラーの波：`TemplateNotFound`, DB 初期化漏れ, push 失敗…  
  → そのたびに**再現 → 切り分け → 修正**を徹底
- でも、乗り越えるたびに**理解が立体化**していく実感があった

---

## 取り組み概要（成果）
- **課題①：連絡帳管理PoC（Flask + SQLite）**  
  - 前登校日のみ提出／(student_id,date)重複禁止／既読はPOST  
  - `templates/index.html` の最小UI、`seed.py` でデータ投入
- **課題②：運用拡張**  
  - `/status` 提出状況、`/analytics` 週次分析  
  - `/shared_notes` 共有メモ、`/search` 横断検索
- ドキュメント：**README完全版**、Marpスライド、`.env.example` / `.gitignore`

---

## スクリーンダイジェスト
- 提出フォーム：**前登校日**を初期値、当日は**バリデーションでブロック**  
- 一覧：**既読はPOST**ボタンで確実に反映  
- 提出状況/分析：未読・最終提出・平均スコア、**週次の傾向**を可視化  
- 共有メモ：担任間の知見を**時系列で共有**

---

## 楽しかったこと（学生時代を思い出した瞬間）
- 仕様をどうコードに**落とし込むか考える時間**が純粋に楽しい  
- 少しずつ通るようになっていく**緑のテスト感覚**  
- 問題を調べ、仮説を立て、実験する**研究室の感覚**が戻ってきた

---

## つまずき & 解決のパターン
- `TemplateNotFound` → **templates/ の命名 & カレントディレクトリ**の統一  
- **DB 初期化漏れ** → `seed.py` と `before_first_request` で担保  
- **push 失敗** → `git pull --rebase` を運用に定着  
- **PowerShell 実行ポリシー** → `RemoteSigned` で解決  
→ ノウハウを README とスライドに**明文化**して再発防止

---

## 学び（技術面）
- バリデーションは**UIではなくサーバ側**で担保する設計が効く  
- **最小構成**でまず動かす → その上に小さく積む  
- 依存・ランタイム・seed・README を**セットで整備**すると再現性が上がる

---

## 学び（働き方・姿勢）
- 「**分からないときの最短ループ**」を作る  
  - 事象 → 再現手順 → 切り分け（入力/環境/コード） → 修正  
- **仮説→検証の速度**が自信につながる  
- 失敗は**ログと記録**で資産化（次に効く）

---

## 定量・定性インパクト（想定）
- 朝の提出確認：**数分 → 数十秒**  
- 未読・未提出の取りこぼしを削減  
- 学年会議の準備：共有メモで**転記作業を削減**

---

## 残課題（やり切れていない部分）

- **祝日連携**で前登校日の厳密化

- **管理GUI** と **CSRF/認証強化**
