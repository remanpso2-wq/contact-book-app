# 学校連絡帳管理 PoC

学校現場で使用されている「連絡帳（体調・メンタル・振り返り）」をデジタル化し、  
**提出状況の可視化・担任の確認作業の効率化・週次分析・担任間の情報共有** を実現した Web アプリです。

課題①（基本CRUD＋提出制限）をベースに、**課題②として実運用を意識した分析・共有・検索等の拡張機能**を実装しました。

---

## 🔎 プロジェクト概要

- **目的**：担任の負担軽減・紙連絡帳の課題改善・提出状況の早期把握  
- **利用者**：生徒（提出）、担任（承認・確認・分析）、管理者  
- **技術**：Python / Flask / SQLite / SQLAlchemy / Jinja2 / Chart.js  
- **担当範囲**：実装・画面構成・集計処理・仕様策定（個人）

---

## ✨ 実装機能（課題②で追加）

### ● 1. 週次分析 `/analytics`
- 直近 12 週の提出数・平均スコアを自動集計  
- 折れ線＋棒グラフで変動を可視化  
- 対象週の傾向把握に利用できる

### ● 2. 提出状況 `/status`
- クラスごとの提出率・未提出者数・最新提出日  
- `?grade=3&class=A` のようにクエリで絞り込み可能  
- 30日/90日/全期間の集計切り替え

### ● 3. 担任間共有メモ `/notes/shared`
- 生徒別の気づき・指導事項を共有  
- 学年会議の準備時間を短縮

### ● 4. 横断検索 `/search`
- 生徒名・本文・日付をまとめて検索  
- 行クリックから詳細へ遷移

---

## 🖥 画面・ルート一覧

| 画面 | ルート | 概要 |
|---|---|---|
| ホーム | `/` | 一覧・検索導線 |
| 新規提出 | `/add` | 前登校日のみ、重複提出禁止（`student_id, date`） |
| 検索 | `/search` | キーワード検索 |
| 生徒詳細 | `/student/<id>` | 折れ線グラフ、提出率、既読処理 |
| 既読処理 | `/check/<report_id>` (POST) | CSRF対応 |
| 提出状況 | `/status` | 提出率・最新提出日・クラス絞り込み |
| 週次分析 | `/analytics` | 12週の提出数＋平均スコア |
| 担任メモ | `/notes/shared` | 共有メモ／検索／追加 |

## 🧱 データモデル（ER 概要）

- `Report(date)` は `"YYYY-MM-DD"` 形式（実装簡略のため文字列）  
- 主な Index：  
  - `Report(student_id, date)`  
  - `Report(is_checked)`  
  - `TeacherNote(student_id, date)`

---

## 🛠 設計・実装上の工夫（企業向けポイント）

- **課題①のテーブル構造に追加して拡張** → 運用コストを最小化  
- 集計処理は SQLAlchemy の `func` で**SQL側に寄せて高速化**  
- 絞り込みは URL パラメータで統一し、**画面遷移を最小化**  
- 既読処理は **POST限定＋CSRF Token** により誤操作防止  
- 週次分析の週番号判定など、日付ロジックをサーバサイドへ寄せて安定化

---

## 🧩 技術選定の理由

### ● Flask
- シンプルなルーティングとテンプレート構成  
- 小規模PoCを短期間で作るのに適している  
- SQLAlchemy との相性が良い

### ● SQLite
- 環境構築が軽量で PoC 評価に向く  
- 単一ファイルで持ち運びが容易
